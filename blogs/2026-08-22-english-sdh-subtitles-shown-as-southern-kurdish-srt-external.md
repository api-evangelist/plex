Server Version#: 4.160.0 Player Version#: Web The issue: For example, naming an SRT file Drive (2011).en.srt produces under the movie’s subtitles English (SRT External) That’s correct. But naming an SRT file Drive (2011).en.sdh.srt (a subtitle file for the deaf and hard of hearing) produces under the movie’s subtitles Southern Kurdish (SRT External) That is not correct. ISO for Kurdish is KU or KUR , and the Plex Articles state that SDH subs should be named Movie Title (Year).en.shd.srt So why does Plex interpret en.sdh.srt as Souther Kurdish ?
