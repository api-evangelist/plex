# Plex

> Plex, Inc. builds Plex Media Server — self-hosted software that organizes,
> transcodes and streams a person's own movies, TV, music and photos to Plex apps on
> nearly every platform — alongside a free ad-supported live TV and on-demand
> catalog, Discover, Rentals, the Plexamp music player and the paid Plex Pass tier.
> In September 2025 Plex published official documentation for the Plex Media Server
> HTTP API for the first time: an OpenAPI 3.1 contract of 258 operations across 205
> paths, a new public-key JWT authentication flow on plex.tv, and an
> OAuth-protected remote MCP server for agents.

## Key facts for an agent

- Plex Media Server is **self-hosted**. There is no shared production API host. A
  server is reached on the LAN at `http://<ip>:32400` or remotely at
  `https://<ip-with-dashes>.<machineIdentifier>.plex.direct:32400`.
- Authentication is the `X-Plex-Token` header on every request. The value is either
  a legacy long-lived token or a 7-day Plex JWT (Ed25519 / EdDSA).
- Responses are **XML by default**. Send `Accept: application/json` for JSON.
- Pagination is by `X-Plex-Container-Start` / `X-Plex-Container-Size` request
  headers; verify the response actually paginated before trusting it.
- API version is declared by the `X-Plex-Pms-Api-Version` request header. Absent
  the header the server assumes `0.0` and the pre-1.0 field semantics.
- There is **no idempotency contract**, **no rate-limit signalling**, and **no
  structured error body**. Errors are HTTP status only.

## APIs

- [Plex Media Server API](https://developer.plex.tv/pms/): the official HTTP API on
  every Plex Media Server — libraries, metadata, playlists, collections, play
  queues, sessions, activities, butler tasks, preferences, download queue,
  transcoding, DVR / EPG / Live TV, and WebSocket + SSE notification streams.
- [Plex Account and Authentication API](https://clients.plex.tv/api/v2): PIN device
  linking, JWK registration, nonce issuance and device-JWT exchange for a Plex JWT.
- [Plex MCP Server](https://plex.tv/internal/mcp): first-party remote Model Context
  Protocol server, OAuth 2.1 + PKCE, single scope `mcp`. Tool list is auth-gated.
